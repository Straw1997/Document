# UE 资产分析明细数据

本数据包对应《UE资产分布分析报告》，由 UEX 精确扫描结果整理而成。

## 统计口径

- 角色：按“逻辑角色 → 视觉装配”组织。角色本体与配套武器合并；Pet 单列；Show、World、InCar 等互斥状态不叠加。
- 三角面：来自解包资产中可读取的各 LOD 索引数据。`character_lods.csv` 同时保留原生 LOD 与末级延用后的有效 LOD 口径。
- 骨骼：`reference_bones_unique` 为同骨架组件去重后的参考骨骼数；`active_bones_proxy` 是按同骨架组件取最大值的 LOD 骨骼代理值。
- 动画：只统计通过精确 `skeletonPath` 关联的 AnimSequence。`frame_count` 为资产实际帧数；直方图每 30 帧一档，超过 600 帧合并到尾档。
- 纹理：通过 Mesh → Material → Texture 精确关联，只报告分辨率。场景主统计包含 Texture2D 与 Texture2DArray；TextureCube 单列。
- 场景：只保留“大建筑、植被、其他”三类；排除测试、占位、碰撞、代理、技术辅助和影视专用模型。场景图表只使用 LOD0。

## 目录

- `角色数据/character_summary.csv`：每个视觉装配的核心汇总。
- `角色数据/character_lods.csv`：每个装配、每层 LOD 的三角面与骨骼指标。
- `角色数据/character_animation_histogram.csv`：每个装配的动画帧数分布。
- `角色数据/character_animations.csv`：逐动画片段的时长、帧数和采样率。
- `角色数据/character_texture_resolutions.csv`：每个装配的纹理分辨率分布。
- `角色数据/character_meshes.csv`、`character_textures.csv`：逐模型和逐纹理明细。
- `角色数据/logical_characters.csv`：逻辑角色层级汇总。
- `角色数据/module_library_*.csv`：无法可靠拼成单一角色的模块化 NPC 库。
- `场景数据/environment_category_summary.csv`：三类场景资产总览。
- `场景数据/environment_triangle_histogram.csv`：LOD0 三角面分布。
- `场景数据/environment_texture_resolutions.csv`：纹理分辨率分布。
- `场景数据/environment_meshes.csv`、`environment_mesh_lods.csv`、`environment_textures.csv`：逐资产明细。
- `场景数据/environment_excluded_meshes.csv`：被排除模型及原因，便于复核。
- 两个目录中的 JSON 文件用于复现离线图表。

## 质量说明

- 扫描置信度：Strong。
- 扫描资产：102,836；关系：1,364,646；扫描错误：0。
- 自动校验：57 项通过、0 项失败、1 项提示。
- 唯一提示：1,597 个场景模型存在非传统的 cooked/Nanite fallback LOD 顺序，因此场景只展示 LOD0 分布，不推断完整 LOD 趋势。
